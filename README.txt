# 📚 Book Tracker

**Автор:** [Анастасия Гредасова]
**Дата:** [29/04/2026]

## Описание программы

*Book Tracker* — это простое графическое приложение для ведения списка прочитанных книг. Программа позволяет добавлять новые книги с указанием названия, автора, жанра и количества страниц. Реализована фильтрация по жанру и количеству страниц. Все данные сохраняются в формате JSON для последующего использования.

## Технологии

*   **Язык:** Python 3.x
*   **Библиотека GUI:** Tkinter (встроенная)
*   **Хранение данных:** JSON

## Инструкция по запуску

1.  Установите Python версии 3.7 или выше с официального сайта (если он еще не установлен).
2.  Скачайте или склонируйте этот репозиторий на свой компьютер.
3.  Откройте терминал (или командную строку) и перейдите в папку с проектом.
4.  Запустите приложение командой:
    ```bash
    python book_tracker.py
    ```
    Или просто дважды кликните по файлу `book_tracker.py`.

## Примеры использования

1.  **Добавление книги:**
    *   Заполните все поля: *Название*, *Автор*, *Жанр*, *Страниц*.
    *   Нажмите кнопку «➕ Добавить книгу».
    *   Книга появится в таблице сверху.
2.  **Фильтрация:**
    *   Чтобы найти книги определенного жанра (например, «детектив»), введите слово в поле «Фильтр по жанру» и нажмите «🔎 Фильтровать».
    *   Чтобы найти объемные книги (более 300 страниц), введите число «300» в поле «Фильтр по страницам» и нажмите «🔎 Фильтровать».
3.  **Сохранение данных:**
    *   Нажмите кнопку «💾 Сохранить в JSON». Все добавленные вами книги сохранятся в файл `books.json`.
4.  **Загрузка данных:**
    *   При следующем запуске программа автоматически загрузит данные из файла `books.json`, если он существует.
